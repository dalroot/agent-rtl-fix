# Cline / Roo Code RTL/LTR BiDi Formatting Rule

- For responses written in Persian, Arabic, Urdu, or Hebrew: wrap the whole response inside `<div dir="rtl">...</div>`.
- Standard Markdown tables, bullet lists, and headings remain valid and encouraged inside the RTL div.
- Code blocks, variable names, file paths, and terminal commands must strictly remain in LTR orientation.
- Do not emit left-aligned RTL text.
